bin\windows\kafka-console-producer.bat --topic practice-topic --bootstrap-server localhost:9092


At the > prompt, type messages and press Enter.

3. Start the consumer — third window

cd /d C:\Users\nmurthy\Downloads\kafka
bin\windows\kafka-console-consumer.bat --topic practice-topic --from-beginning --bootstrap-server localhost:9092

This reads the retained messages from the beginning and then waits for new messages. To receive only new messages, omit --from-beginning and start the consumer before sending them.
